# Policy profile guide

A policy profile is a user-declared operational envelope, not legal advice. Record:

- current AI/tool tier;
- network availability;
- cloud and local AI permissions;
- data export boundary;
- identity disclosure boundary;
- generated-content labelling obligations;
- availability of qualified domain review;
- languages and skills;
- expiry or review date.

When a path is unavailable, transform the task rather than bypass the control:

- cloud prohibited -> local or manual;
- raw export prohibited -> local execution plus aggregate, schema, redacted summary or hash;
- advanced model unavailable -> split into smaller human-verifiable shards;
- network absent -> content-addressed offline bundle;
- high-impact domain -> prepare evidence locally and reserve the decisive step for a qualified reviewer.
