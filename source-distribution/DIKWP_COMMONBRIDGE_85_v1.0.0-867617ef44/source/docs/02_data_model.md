# Data model

## Capsule

A bounded project with D/I/K/W/P, identity boundaries, tasks and MESH8.5 responsibility state.

## Environment profile

A temporary, user-declared capability and policy envelope. It is not legal advice and not a human ranking.

## Route plan

A task-by-task mapping to direct, manual, local-only, hash-only, review-hold or currently unavailable routes.

## Contribution

A scope-limited result with source, artifact, unresolved differences, review status, attribution and correction rights.

## True-value receipt

A non-financial, non-transferable, revocable record of observed world effect. It cannot become a person score.

## Offline exchange bundle

A ZIP containing the capsule, route, contributions, receipts and SHA-256 manifest. It has no proxy, credential or external execution function.
