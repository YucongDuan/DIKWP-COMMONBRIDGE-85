# Architecture

COMMONBRIDGE-85 has seven planes:

1. **Problem and source plane** - real need, source, version and local context.
2. **D/I/K/W/P capsule plane** - source facts, differences, bounded understanding, affected worlds and purpose.
3. **Capability environment plane** - current manual/local/hosted/institutional tools; never a person grade.
4. **Policy adaptation plane** - task transformation, data minimization, labelling and high-impact review.
5. **Task-shard plane** - independent units with manual fallback and true-value intent.
6. **Contribution and offline exchange plane** - content hashes, manifests, attribution, dispute and delay tolerance.
7. **World-effect plane** - observed benefit, burden, affected-party feedback, correction and reopening.

The reference runtime is Python standard library + SQLite + native HTML/CSS/JavaScript. External model networking, credentials and external write-back are absent.
