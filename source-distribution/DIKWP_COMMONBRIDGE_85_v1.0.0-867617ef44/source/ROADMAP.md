# Roadmap

## v1.0 - Public cooperation capsule

- capability-neutral tasks;
- manual and local fallbacks;
- offline exchange bundles;
- scope-limited contribution and true-value receipts;
- proactive open calls;
- static and local-server interfaces.

## v1.1 - Community interoperability

- signed bundle adapters;
- multilingual terminology maps;
- repository and issue import;
- accessibility and low-bandwidth packs;
- independent implementation conformance.

## v2.0 - Federated commons

- opt-in federation between independent communities;
- contribution dispute protocol;
- cross-instance provenance without global person identity;
- public world-effect and correction registry;
- standards-oriented schema release.
