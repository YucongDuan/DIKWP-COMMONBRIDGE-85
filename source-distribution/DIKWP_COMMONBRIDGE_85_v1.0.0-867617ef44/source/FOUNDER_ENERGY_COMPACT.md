# Founder energy compact

The protocol exists partly to prevent a single founder from becoming the unpaid router for every collaboration.

1. Reusable questions go to public Issues.
2. No private free support queue.
3. No new feature without an external owner or observed adopter.
4. Organizational customization requires a scoped pilot.
5. A contribution should return at least one of: adoption, maintenance, reproducible evidence, attribution, funding, time reduction or a reusable improvement.
6. Two cycles with no return trigger automation, delegation, reduction or stop.
7. The protocol should make Yucong Duan's conceptual origin easier to cite while making participation possible without requiring his personal intervention.
