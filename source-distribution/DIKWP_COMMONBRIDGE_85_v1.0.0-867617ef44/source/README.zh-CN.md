# 共桥 COMMONBRIDGE-85

**任何个体、任何合规AI等级、一个可验证贡献。**

共桥面向一个正在出现的现实：国家、机构、平台、出口管制、费用、网络和语言条件，可能把AI能力切分为不同等级。系统不绕过法律、平台或技术控制，而是把同一个DIKWP协作项目编译成多条合法路径：

- 完全不用AI的人工路径；
- 本地规则和轻量工具；
- 小型本地模型；
- 受限云端模型；
- 高级云端工具；
- 获得授权的机构级代理。

系统描述的是**当前任务与环境**，不是人的永久等级。它不建立个人总分、意识形态分、能力阶层、金融代币或社会信用。

## 一句话使用

```bash
python start_showcase.py
```

浏览器打开：

```text
http://127.0.0.1:8784
```

没有Python时，直接双击 `index.html`。

## 系统实际完成什么

1. 把真实问题编译成D/I/K/W/P协作胶囊；
2. 分解为不同能力条件都能承担的任务；
3. 根据当前环境生成合法路径；
4. 云端受限时保留本地或人工退路；
5. 数据不能输出时只交换结构、摘要、聚合或哈希；
6. 记录来源、版本、贡献和归因；
7. 现实效果出现后生成范围有限的非金钱真价值凭证；
8. 主动寻找尚未被承担的翻译、本地知识、独立复核和结果观察任务。

## 为什么不是“突破监管”

本系统要突破的是**能力垄断、平台锁定、知识中心化和贡献剥离**，而不是突破法律边界。它不包含代理、隧道、凭证规避、出口管制规避或内容标识删除能力。

## 非金钱真价值

系统分别记录：真相可达、主体自主、照护、修复、贡献承认、学习、未来选择、生态连续、共同体信任和时间返还。

真价值凭证：

- 不可交易；
- 不可转让；
- 不可兑换为人格等级；
- 不构成社会信用；
- 只在具体任务和已观察结果范围内成立；
- 新证据出现后可以撤销或重开。
