# Contributing

Useful contributions include manual workflow improvements, local-language translations, new synthetic examples, independent verification, accessibility fixes, policy-profile templates, result observations and correction cases.

A contribution must not:

- add person ranking, ideology scoring or social credit;
- add proxy, VPN, credential sharing, access-control bypass or sanctions/export-control evasion;
- turn true-value receipts into a transferable or financial token;
- silently remove provenance or unresolved differences;
- claim to represent Yucong Duan or another contributor without explicit authorization.

Use Issues before creating a separate repository. A new repository requires a new external maintainer, adopter, dataset, falsifiable experiment, standard interface, funded workflow or legally required separation.
