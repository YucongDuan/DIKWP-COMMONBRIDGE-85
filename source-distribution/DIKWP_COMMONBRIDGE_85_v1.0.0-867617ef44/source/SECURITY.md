# Security policy

Report vulnerabilities through a private channel chosen by the repository owner. Do not include real personal data, credentials or restricted material in a public issue.

High-priority findings include:

- unsafe ZIP paths or manifest bypass;
- leakage of private identity through public exports;
- removal of provenance or generated-content labels;
- code that adds proxy, tunnelling, credential or unauthorized network behavior;
- conversion of true-value receipts into person ranking;
- audit-chain tampering.

The reference runtime has no external write-back, shell, credential or model-network tool.
