# Adversarial attention and gatekeeper model

Assume that some participants may strip origin, demand free customization, use compliance language to exclude rivals, poison data, impersonate contributors, capture governance, lock the protocol to one vendor, or turn contribution receipts into a ranking market.

The system response is structural rather than moralistic:

- content-addressed origin and lineage;
- explicit public/private scope;
- no global person score;
- no transferable token;
- issue-first support;
- manual fallback;
- independent review and appeal;
- no external write-back by default;
- world-effect and correction obligation.
