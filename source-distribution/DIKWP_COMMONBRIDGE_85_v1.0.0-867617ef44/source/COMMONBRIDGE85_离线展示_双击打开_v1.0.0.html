01

任务分级，不给人分级

系统只描述当前工具环境与任务敏感度。它不形成永久个人等级，也不用于社会资格判断。

02

降级执行，不绕过控制

云端受限时转向本地或人工；数据不能输出时仅交换模式、摘要、聚合或哈希。

03

延迟容忍交换

内容寻址ZIP可经用户合法控制的文件、邮件、移动存储或机构通道交换并离线核验。

04

生成内容可识别

保留模型、版本、提示、人工修订和来源元数据，不帮助删除或伪造生成标识。

05

高影响最小复核

医疗、法律、金融、就业和公共安全的决定性步骤进入合格复核，不让所有前置工作停摆。

06

政策档案由用户声明

参考实现不假装自动给出全球法律意见；当地义务应由合法主体更新和复核。

ADVERSARIAL HUMAN MODEL

把人性想得足够现实，才能保护开放合作

系统默认会遭遇来源剥离、免费劳动抽取、冒充、门槛滥用、数据投毒和价值凭证游戏化。

SOVEREIGN & PORTABLE

一个共享协议，不依赖一个平台或一个模型

D/I/K/W/P是协作核心；模型、国家、平台和算力只是可替换载体。
